# ASR 专名同音纠错（佐武と市 → サブト位置）

> 现象：`佐武と市` 被 Qwen3-ASR 转成 `サブト位置`——`位置` 读 `イチ`，与 `市` 同音。
> 下游翻译只能看到 `位置`，于是照字面译成「世间暗处」，名字彻底丢失。
> 结论：**这类问题必须在转写文本层修，翻译层救不回来。**

## 1. 为什么不能在翻译/词表层兜底

- 词表能映射 `サブト位置 → 佐武与市`，但那是**事后猜**：模型已经根据 `位置` 生成了中文；
  词表只在中文侧做替换，ASR 原文仍然错，下一批/下一集还会错。
- 也不能靠「字面相似」：`位置` 与 `市` 在中文里完全不同形，只能靠**读音**对齐。

## 2. 实测：错误形态有多少

22 集日文参考字幕（都是 ASR 产物）里，`サブ*` 形状 30 种：

| 形状 | 次数 | 性质 |
|---|---:|---|
| サブ | 153 | 昵称/正确 |
| サブトイチ | 30 | 正确合称 |
| サブヤン | 28 | 昵称 |
| サブト | 6 | 截断 |
| サブル / サブヤー / サブヤモン / サブッケー / サブトミドイ … | 各 1–5 | 听写噪声 |
| サブト位置 | 5 | **同音替换（本文要修的）** |

## 3. 方案（四层，按性价比排序）

### L0 读音表（人工确认，唯一决策源）

`_meta.readings` + `_meta.canonical_ja`：

```json
"readings": {"佐武": ["サブ"], "市": ["イチ"], "サブトイチ": ["サブトイチ"]},
"canonical_ja": {"サブ": "佐武", "サブトイチ": "佐武と市", "イチ": "市"}
```

**不能用 janome 的读音**：它把 `佐武` 读成 `サタケ`、`市` 读成 `シ`；
名字读音只能人工给。janome 只拿来分词。

### L1 读音级纠错（已实现：`lib/asr/namefix.py`）

1. janome 分词，取每个词的**片假名读音**（片假名词的 reading 是 `*`，用 surface 兜底）；
2. 把 1–3 个名词性词拼成窗口，拼读音与 L0 读音表做**精确**匹配；
3. 命中就替换成规范日文形（`佐武` / `市` / `佐武と市`），记录原词、读音、位置。

安全规则（都有测试）：

| 规则 | 原因 |
|---|---|
| 只有**精确**读音匹配默认启用 | 近音替换实测 10 处里有多处毁词（`バカ野→バカ`、`サブ君→佐武` 丢敬称） |
| 非片假名 surface 默认不改 | 单独一个 `位置` 会被改成 `市`（实测误伤）；只有 `サブト位置` 这种窗口（含片假名）才动 |
| `サブタイトル` 这类整词不动 | janome 不拆词，读音不匹配 |
| 规范形已在文中 → 跳过 | 幂等，重复跑无副作用 |
| 不改时间轴、不改翻译 | 职责分离；闸门仍然生效 |

22 集实测：**236 条 cue / 241 处**（全部 `distance=0`）：

| 替换 | 次数 |
|---|---:|
| サブ → 佐武 | 154 |
| サブトイチ → 佐武と市 | 30 |
| サブヤン → 佐武 | 28 |
| イチアン → 一庵 | 13 |
| イチ → 市 | 11 |
| **サブト位置 → 佐武と市** | **5** |

### L2 ASR 热词/上下文（未启用，需 A/B）

`ASR_CONTEXT_FILE` / `--asr-context` 已支持，把 L0 词表塞进 Qwen3 的 system 提示。
已有证据：hotwords 改善文本但**时间轴变差**，所以只能用于「文本修复专用」路线：
同一段音频跑两次（带/不带热词），文本取带热词版、时间轴取原版。
这条要先在 1–2 集上量名字命中率与 P50/P90，达标才进默认。

### L3 固定句（OP/预告）

`サブト位置` 出现在 OP 旁白里，整句是固定的：

```
罪は憎いが憎まぬ人を切るも縛るも人のため
闇を切り裂く男行きおぼろずき世のサブト位置
```

这两句不靠 ASR、也不靠词表，直接按**行模板**替换（52 集共用），
和上一个方案里的 fixed-lines 机制合并实现。

### L4 闸门与审计

- 每次纠错写日志（原词/读音/位置/规则），可抽样复核；
- `text_gate` 增加「人名残留」计数：规范名出现次数与词表命中次数不一致就报警；
- 近音替换、白名单 kanji 表面（如 `位置`）都必须经过 `_meta` 显式开启。

## 4. 局限（说清楚，不吹）

- 只解决**同音/读音可对**的错误；`サブル`、`サブッケー` 这类截断/插入要靠近音或人工。
- 新角色没进读音表就修不了；每季新增专名要补表（可复用 `discover_variants` 的思路：
  在「名字应出现」的 cue 里找高频字串）。
- 非人名同音词（`位置`、`一`、`市` 等）需要白名单控制，不能全局替换。
- 时间轴、翻译、风格都不在本文范围。

## 5. 接入顺序

```
ASR → [L1 读音纠错] → 翻译（glossary）→ [中文变体归一] → text_gate
                     ↑ L2 热词（可选，需 A/B）
```

- L1 放在 `video_to_zh` / `fix_by_asr` 写出 ja SRT 之前；
- L3 固定句放在 L1 之后（行级覆盖）；
- 中文侧归一与闸门已经在用（`docs/glossary-variants.md`）。

## 6. 测试

`tests/test_namefix.py`（12 例）：同音窗口修复、`位置` 单用不误伤、敬称保留、
整词不拆（`サブタイトル`）、幂等、近音默认关、白名单、未给读音的汉字跳过。
