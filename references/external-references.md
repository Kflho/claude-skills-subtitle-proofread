# 作品外部参考：开项目前的第 0 步

字幕翻译的真相源有两层：**音频里听到什么**（ASR）和**正确的写法是什么**（外部参考）。
ASR 只能回答第一层。名字、招式、歌词、集号、时代用语一旦只依赖 ASR，就会得到
「赤道」「千葉秀作」「スズノスケ」这类错字，而且错得系统性——闸门（kana/变体）
根本拦不住，因为它们看起来是合法日文。

所以新项目的顺序是：**先建外部参考档案，再跑 ASR，再翻译**。

## 可信度阶梯

同一件事有两个来源时，按这个顺序取：

| 级别 | 来源 | 用途 |
|---|---|---|
| 1 | 制作公司作品页、官方设定集、官方站点 | 话数/时长/声优/曲目，最硬 |
| 2 | 动画数据库（allcinema、Anison Generation、tvdrama-db 等） | 曲目、歌手、作词作曲、放送局 |
| 3 | 百科（ja.wikipedia 最细；zh.wikipedia 看通行译名） | 分集表、设定、人物关系 |
| 4 | 歌词站（UtaTen、JOYSOUND、Uta-Net） | OP/ED 逐句歌词（授权歌词） |
| 5 | 社区（B站简介/评论区、豆瓣、贴吧） | 只做**线索**，要回到 1–4 核实 |
| 6 | 机翻站、搬运号 | 不作为依据 |

网络不通时的降级：B站 API、UtaTen、JOYSOUND 国内可直连；维基/番组计划常超时，
拿不到就**记下缺口**，不要用搜索摘要硬凑设定。

## 要查什么（A–J）

| # | 参考 | 用来定什么 | 落到哪 | 常见坑 |
|---|---|---|---|---|
| A | 作品与版本 | 年份、话数、单集时长、制作公司、**哪一版** | 项目 CLAUDE.md | 漫画/実写/新旧动画同名，译名被串用 |
| B | 中文通行译名 | 作品名、人物名的中文写法 | 词表 canonical | 自创译名；同一角色几种写法 |
| C | 人物表 + 关系 + 称呼 | 谁叫谁「殿」「貴様」「お前」、辈分 | 译名 + 语体规则 | 把「兄弟子」译成「哥哥」 |
| D | 专名读音（片假名） | namefix 修 ASR 同音字 | `_meta.readings` / `canonical_ja` | 表要按 **janome 实际读法**写（赤道=セキドウ） |
| E | 招式/组织/门派 | 术语统一 | 词表 | 同一招在集间写成两种中文 |
| F | OP/ED 曲名 + 歌词 + 集号范围 | 片头片尾定稿译文 | `_meta.op_map` / `fixed_lines` / `oped_fixer` | 中期换 ED；ASR 对唱词是乱写 |
| G | 分集副标题 | 标题卡、次回预告 | 可选，报告/发布说明 | 副标题和剧情对不上，说明集号错位 |
| H | 集号对照（投稿 P / 話数 / 碟） | 防集号错位 | 项目 CLAUDE.md 的映射表 | 英版 E01/E02 与 DVD P1/P2 对调（实测过） |
| I | 时代/职业用语 | 江户、战国、昭和职场用语 | 词表 + 语体（写成译法对照） | 同一时代词集间几种译法；写法按当代表达 |
| J | 上游结构化元数据 | 页数、每页时长、**有没有字幕轨** | `bili_meta.py` 输出 | 长页是两集合并；AI 字幕当参考 |

## 查法（可直接抄）

```bash
# 上游结构：页数、每页时长、有没有字幕（无字幕 = 只能 ASR）
python scripts/acquire/bili_meta.py --bvid BV... --out bin/reference_docs/bili_meta.json
```

搜索句式（一次查一类，别混）：

```text
<日文原名> 1972 アニメ 各話リスト サブタイトル
<日文原名> 公式 キャスト 主題歌
<日文原名> OP 歌詞
<日文原名> ED 歌詞 <曲名>
<日文原名> 中文译名 角色
<日文原名> 時代 設定 用語
```

## 落地

1. 建 `bin/reference_docs/<作品>_外部参考.md`：来源链接 + 抓到的原文 + 缺口；
2. 名字与招式 → `data/glossaries/<series>.series.json`（扁平 ja→zh）；
3. 读音 → 同目录 `.meta.json` 的 `readings` + `canonical_ja`；
4. 歌词 → `.meta.json` 的 `op_map`（逐句原文→译文），交给 `oped_fixer` /
   `context_review --mode oped` 统一；没有逐句表就别用「窗口里最多的一句」兜底；
5. 集号映射 → 项目 `CLAUDE.md`（别只放在脑子里）；
6. 跑 ASR 前做一次「映射完整性检查」：源里出现的书写形式是否都有条目。

## 版权与边界

- 歌词站是**授权歌词**，只用于内部翻译参考；不要把整段日文歌词贴进 README、
  发布说明或字幕以外的文件；
- 中文译文自己写，不整段搬运别人的字幕/译文；
- 外部参考用来定**写法和事实**，不用来替代看片：语气、停顿仍以画面为准。
